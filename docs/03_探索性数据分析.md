# 03 探索性数据分析

---

## 1. 订单下单时段分布分析
### 分析思路
通过 `HOUR()` 函数提取订单购买时间的小时数，按小时分组统计订单数量，分析用户单日下单的高峰与低谷时段，以此为平台日常运营排班、活动投放提供参考依据。

### 分析结论
订单时段分布具备清晰的作息规律：凌晨2点至4点订单量处于全天最低水平，属于用户休息下单低谷；上午10点到下午16点是下单最高峰，用户消费活跃度最高；晚间20点至21点形成次高峰，订单交易热度同样可观，整体下单节奏贴合大众日常作息习惯。

## 2. 订单状态分布分析
### 分析思路
以订单状态为分组依据，统计各类状态对应的订单数量，梳理平台订单履约整体结构，评判履约效率与订单整体健康水平。

### 分析结论
平台整体履约表现优异，业务运转状态健康。已完成交付订单共计96478单，占比超96%，是订单主体部分；已发货未签收、订单取消、商品缺货类订单数量均控制在千单以内，对整体履约效率影响较小。后续可深挖取消订单、缺货订单产生原因，优化供应链备货与售前服务，进一步降低无效订单占比。

## 3. 支付方式分布分析
### 分析思路
按照支付类型分组统计订单笔数与交易总额，剖析用户支付偏好，掌握各类支付渠道的交易贡献占比，理清平台整体支付结构特点。

### 分析结论
平台支付方式呈现明显的单一主导格局。信用卡是用户首选支付渠道，订单笔数达到76795笔，交易总额突破1254万雷亚尔，订单量与交易额均占据绝对优势；票据支付使用频次次之，订单数接近2万笔，交易额约287万雷亚尔；代金券、借记卡使用占比较低。仅有3笔无定义支付订单且金额为0，不会干扰整体交易统计。用户支付选择高度集中，主流支付渠道承载了绝大部分交易订单。

## 4. 用户评价评分分布分析
### 分析思路
依据评价分数分组统计评论条数，研判整体用户满意度高低，区分好评、差评占比情况，找准用户体验现存问题，为服务优化指明方向。

### 分析结论
用户评价整体偏向正向好评，平台口碑基础良好。5分好评数量最多，共计57328条，直观体现多数用户消费体验满意；4分好评占比次之，两类高分评价合计占据绝大多数评价数据。同时1分差评共有11424条，差评规模不容忽视。后续针对差评订单溯源核查，重点整改物流配送、商品品质、售后沟通等高频投诉问题，补齐服务短板。

## 5. 订单地域分布分析
### 分析思路
关联客户表与订单表，以用户所在州为统计维度汇总订单数量，探究订单区域分布规律，划分核心消费区域与低渗透区域，为区域运营布局、仓储物流规划提供数据支撑。

### 分析结论
订单地域呈现两极分化的集中式分布特征，整体订单体量由东南部沿海区域向内陆、北部区域逐步递减。RR、AP、AC等偏远州县订单不足百单，市场渗透率偏低；圣保罗州、里约热内卢等东南部经济发达地区订单体量遥遥领先，是平台核心消费市场。订单分布和区域经济发展水平高度契合，后续可深耕核心区域加大运营投入，针对冷门区域开展市场调研，挖掘潜在消费市场。

## 6. 商品品类销量 TOP10 分析
### 分析思路
关联订单项表与商品表，按照商品品类分组统计销售数量，筛选销量排名前十的品类，锁定平台热销产品方向，为商品选品备货、运营资源倾斜提供数据参考。

### 分析结论
平台热销商品以日常刚需品类为主，消费需求贴合生活场景。床品卫浴类商品销量达到11115件，位列所有品类第一，是平台王牌热销品类；美妆健康、运动休闲、家居装饰等高频生活用品紧随其后，共同组成平台主力热销品类矩阵。销量前十品类均聚焦家居、健康、休闲、数码大众消费领域，小众冷门品类未能跻身榜单。后续可重点维护热销品类供应链，同时挖掘潜力品类，丰富平台商品结构。

## 本章小结
本章从下单时间、订单履约、支付渠道、用户评价、地域市场、商品品类六个维度展开全方位探索分析，全面掌握平台整体业务运行现状。

整体来看平台业务发展态势平稳，订单履约效率高，用户整体满意度良好；用户消费行为具备明显共性，下单时段、支付方式、消费地域、选购品类均高度集中，头部效应显著。通过多维度数据分析，清晰识别出平台优势业务、现存短板与潜在增长空间，为后续精准定位业务问题、核算核心经营指标、制定运营优化策略打下坚实的数据基础。
