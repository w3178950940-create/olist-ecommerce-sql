# 03 探索性数据分析

---

## 1. 订单量时间趋势分析
### 分析思路
使用 `DATE_FORMAT` 将订单时间按年月聚合，统计每月订单量，观察平台业务随时间的整体变化趋势。

### 分析结论
本次查询结果显示所有订单均集中在单一月份，未呈现出完整的时间序列趋势，推测是数据导入或格式问题导致时间维度未正常拆分。后续需进一步排查时间字段，再开展月度/季度趋势分析。

---

## 2. 订单状态分布分析
### 分析思路
按订单状态分组统计订单数量，了解平台订单履约情况，判断业务健康度。

### 分析结论
平台订单以已交付为主，占比超97%，履约率极高；取消、无货等异常订单占比极低，平台整体业务健康度良好，后续分析可聚焦已交付订单展开。

---

## 3. 支付方式分析
### 分析思路
按支付方式分组统计订单数与总金额，了解平台主流支付渠道，分析用户支付习惯。

### 分析结论
信用卡是平台绝对主流支付方式，订单数与交易金额均远超其他渠道；银行转账、代金券、借记卡支付占比较低，平台支付渠道结构相对单一，用户支付习惯高度集中于信用卡。

---

## 4. 用户评价分析
### 分析思路
按评价分数分组统计数量，了解平台用户整体满意度，识别评价分布是否存在明显倾斜。

### 分析结论
用户评价以5分好评为主，占比超57%，整体满意度较高；低分评价（1分）占比约11.5%，仍有优化空间，后续可结合低分订单的商品、地域、支付方式做专项分析。

---

## 5. 用户地域分布分析
### 分析思路
关联用户表与订单表，按用户所在州分组统计订单量，了解用户地域集中度，识别核心市场。

### 分析结论
订单高度集中在巴西东南部地区，其中圣保罗州（SP）占比超40%，里约热内卢（RJ）、米纳斯吉拉斯（MG）紧随其后，呈现明显的地域头部效应；偏远地区订单量极少，后续可针对核心市场优化运营资源配置。

---

## 6. 商品品类销量TOP10分析
### 分析思路
关联订单项表与商品表，按品类分组统计销量，识别平台热门品类，了解用户消费偏好。

### 分析结论
家居用品类（cama_mesa_banho）为平台销量冠军，远超其他品类；美妆健康、运动休闲、家具装饰等品类销量紧随其后，用户消费偏好集中于生活刚需类商品，后续可针对热门品类开展精细化运营。

---

## 本章小结
通过对时间趋势、订单状态、支付方式、用户评价、地域分布、商品品类的多维度探索分析，已建立对平台业务的全面认知：
1.  平台履约率高、用户满意度较好，业务整体健康度良好
2.  用户支付习惯、地域分布、消费品类均呈现高度集中的特点，存在明显的头部效应
3.  时间维度数据存在格式问题，需后续排查完善
本次分析为后续业务指标计算、问题定位与优化方向提供了明确依据。

-- 03 探索性数据分析 EDA
-- 维度：时间趋势、订单状态、支付方式、评价评分、地域销量、品类销量

-- 1. 按年月统计订单量趋势
SELECT
  DATE_FORMAT(order_purchase_timestamp,'%Y-%m') AS order_month,
  COUNT(order_id) AS order_num
FROM orders
GROUP BY order_month
ORDER BY order_month;

-- 2. 各订单状态数量分布
SELECT
  order_status,
  COUNT(order_id) AS order_num
FROM orders
GROUP BY order_status
ORDER BY order_num DESC;

-- 3. 各支付方式订单数 & 金额统计
SELECT
  payment_type,
  COUNT(*) AS order_count,
  ROUND(SUM(payment_value),2) AS total_amount
FROM order_payments
GROUP BY payment_type
ORDER BY order_count DESC;

-- 4. 评价分数分布统计
SELECT
  review_score,
  COUNT(*) AS review_count
FROM order_reviews
GROUP BY review_score
ORDER BY review_score DESC;

-- 5. 各用户所在州订单量排行
SELECT
  c.customer_state,
  COUNT(o.order_id) AS order_count
FROM customers c
JOIN orders o ON c.customer_id = o.customer_id
GROUP BY c.customer_state
ORDER BY order_count DESC;

-- 6. 商品品类销量 TOP10
SELECT
  p.product_category_name,
  COUNT(oi.order_id) AS sale_count
FROM order_items oi
JOIN products p ON oi.product_id = p.product_id
GROUP BY p.product_category_name
ORDER BY sale_count DESC
LIMIT 10;
