## 问题1：统计平台每个月的订单量，看月度趋势
### 业务需求
查看平台每个月的订单数量变化，了解整体经营趋势。

### 我的思考步骤
1.  **明确核心指标**：订单量（已完成的有效订单数）；维度：月份
2.  **找数据来源**：订单ID、下单时间、订单状态，都在`orders`表
3.  **过滤条件**：只统计`order_status = 'delivered'`的订单，排除取消/未支付的无效订单
4.  **时间处理**：用`DATE_FORMAT(order_purchase_timestamp, '%Y-%m')`把下单时间转成「年-月」格式，方便分组
5.  **分组聚合**：按月份分组，用`COUNT(DISTINCT order_id)`统计订单数（加`DISTINCT`避免重复订单）
6.  **排序验证**：按月份升序排序，看趋势是否连续、合理

## 问题2：统计每月GMV和客单价
### 业务需求
计算每月成交总额（GMV）、订单量、客单价，看平台营收变化。

### 我的思考步骤
1.  **指标拆解**：GMV=支付金额总和，客单价=GMV/订单数，维度：月份
2.  **数据来源**：
    - 月份/订单状态：`orders`表
    - 支付金额：`order_payments`表
3.  **表关联逻辑**：`orders`和`order_payments`通过`order_id`关联，用`INNER JOIN`只保留有支付记录的订单
4.  **过滤条件**：`order_status = 'delivered'`，排除无效订单
5.  **聚合计算**：按月份分组，`SUM(payment_value)`算GMV，`COUNT(DISTINCT orders.order_id)`算订单数
6.  **验证逻辑**：客单价不能为负，且要和业务常识匹配，不能出现异常值
