# 04 多表关联分析

---

## 1. 订单表 + 用户表关联分析
### 分析思路
通过 `INNER JOIN` 关联订单表与用户表，查看每个订单对应的用户ID、唯一用户标识和所在州，建立订单与用户的对应关系，为后续地域分析和用户画像打下基础。

### 分析结论
订单与用户关联关系完整，无孤儿订单，订单数据均能匹配到对应的用户信息。从结果可以看出，订单高度集中在圣保罗州（SP）、里约热内卢（RJ）、米纳斯吉拉斯（MG）等东南部地区，与前期单表分析的地域分布结论一致，验证了数据的一致性。

---

## 2. 订单表 + 支付表关联分析
### 分析思路
关联订单表与支付表，查看每个订单的支付方式和支付金额，了解订单与支付行为的对应关系，为后续分析支付方式对订单的影响提供数据支持。

### 分析结论
绝大多数订单都有对应的支付记录，支付方式以信用卡为主，其次是 boleto（巴西银行转账）和代金券，与前期单表分析的支付方式分布完全吻合。订单支付金额与订单状态匹配合理，无异常金额数据。

---

## 3. 订单表 + 订单项表 + 商品表关联分析
### 分析思路
通过 `INNER JOIN` 三表关联，查看每个订单包含的商品信息，包括商品价格、ID和品类名称，了解订单与商品的对应关系，为后续商品品类分析和订单结构分析提供依据。

### 分析结论
订单与订单项、商品的关联关系完整，无数据缺失。一个订单可以包含多个商品，商品品类覆盖了家居、美妆、运动、数码等多个领域，与前期单表分析的热销品类分布一致，验证了数据的准确性。

---

## 4. 订单表 + 评价表关联分析
### 分析思路
通过 `LEFT JOIN` 关联订单表与评价表，查看每个订单是否有对应的用户评价，以及评价分数，了解订单与用户反馈的对应关系，为后续满意度分析提供数据支持。

### 分析结论
部分订单没有对应的评价记录，属于正常业务情况（并非所有用户都会评价）。有评价的订单中，高分（4-5分）占比很高，用户整体满意度较好；低分评价（1-3分）主要集中在部分特定订单，后续可结合订单状态、商品品类等维度做进一步分析。

---

## 5. 订单 + 用户 + 支付 + 订单项 + 商品五表关联分析
### 分析思路
将订单、用户、支付、订单项、商品五表进行全链路关联，查看订单的完整信息链路，包括用户地域、支付方式、支付金额、商品价格和品类，建立订单的全维度画像。

### 分析结论
五表关联结果验证了各表之间的关联关系完整，数据一致性良好。订单的用户地域、支付方式、商品品类等信息相互匹配，没有出现矛盾或异常数据。例如，来自圣保罗州的用户主要使用信用卡支付，购买的商品以家居用品、美妆健康等热门品类为主，符合前期单表分析的结论。

---

## 本章小结
通过多表关联分析，验证了各业务表之间的关联关系完整、数据一致性良好，建立了订单从用户下单到支付、购买商品、用户评价的全链路数据视图。这为后续基于多维度的业务分析（如不同地域用户的支付习惯、不同品类商品的用户满意度等）打下了坚实基础。
