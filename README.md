# 🛒 Olist 电商数据分析项目（数据分析师求职实战）

基于巴西Olist真实电商数据集，模拟企业数据分析师全流程工作，完成数据清洗、SQL实战、业务指标分析与Tableau可视化，**全程沉淀SQL解题思路与业务逻辑拆解**，打造可验证的实操项目。

---

## 📌 项目背景
Olist是巴西头部电商平台，本项目以其公开数据集为基础，通过数据分析师的视角，解决电商核心经营问题：
- 平台整体经营状况如何？
- 用户留存与复购表现怎么样？
- 商品品类和卖家分布有哪些特点？
- 物流与用户评价反映出哪些服务问题？

---

## 📊 数据说明
本次分析使用Olist 7张核心业务表，覆盖电商全链路数据：
| 表名 | 业务含义 |
|------|----------|
| `customers` | 用户基础信息 |
| `orders` | 订单主表（时间/状态） |
| `order_payments` | 订单支付明细 |
| `order_items` | 订单商品明细 |
| `products` | 商品基础信息 |
| `order_reviews` | 用户评价数据 |
| `category_translation` | 商品品类翻译表 |

---

## 💻 核心分析内容
### 1. SQL 实战练习
- 基础查询：单表统计、分组聚合、时间维度分析
- 多表关联：内连接/左连接/多表嵌套查询，掌握表间关联逻辑
- 高阶查询：子查询/CTE、窗口函数、自连接，解决复杂业务问题
- 性能优化：索引创建、执行计划分析，提升多表查询效率

### 2. 电商核心指标计算
- 经营指标：GMV、订单量、客单价、订单转化率
- 用户指标：30天复购率、用户地域分布、用户分层
- 商品指标：品类销量/销售额排行、商品价格与销量关系
- 服务指标：物流时效、支付方式占比、用户好评率

### 3. Tableau 可视化看板
搭建经营总览、用户分析、商品分析、服务分析4大看板，直观呈现分析结果，支持交互筛选。
