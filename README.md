# 电商平台数据分析项目（MySQL 实战）

## 项目简介
本项目基于巴西电商公开数据集，使用 **MySQL** 完成全流程数据分析：
数据概况 → 数据清洗 → 探索性分析 → 多表关联分析 → 核心业务指标计算 → SQL 索引优化实战。
全程手写 SQL，贴合企业真实数据分析工作流程，可作为简历、课程作业、GitHub 作品集。

## 数据集说明
共 6 张业务表：
- orders：订单主表
- customers：用户表
- order_items：订单项表
- order_payments：支付表
- order_reviews：评价表
- products：商品表

## 分析流程与内容概述

### 01 数据概况
- 各表数据量、用户总量、订单总量、品类数量、支付总额摸底
- 查看订单状态、时间范围、基础字段结构
- 建立对数据集整体业务认知

### 02 数据清洗
统一做三类数据质量检查：
- 缺失值检查：收货时间、用户地区、商品品类、评价分数
- 重复值检查：订单主键、用户唯一ID重复情况
- 异常值检查：商品价格、支付金额 <=0 异常过滤
评估整体数据质量，确定无需大规模清洗，仅少量业务正常缺失。

### 03 探索性数据分析 EDA
多维度单表统计分析：
- 订单时间分布趋势
- 订单状态分布与履约率
- 各支付方式订单量 & 金额占比
- 用户评价分数分布、整体满意度
- 用户所在州订单地域分布
- 商品品类销量排行 TOP10

### 04 多表关联分析
使用 INNER JOIN / LEFT JOIN 完成多表关联：
- 订单 + 用户 关联
- 订单 + 支付 关联
- 订单 + 订单项 + 商品 三表关联
- 订单 + 评价 左连接查看有无评分
- 五表全链路大关联
验证表间关系完整性，构建完整订单业务视图。

### 05 核心业务指标计算
计算电商企业核心大盘指标：
- 平台总 GMV
- 有效交付订单量
- 整体客单价
- 累计消费用户数
- 月度 GMV、月度订单量
- 各商品品类销售额 TOP10
- 各地区销售额 & 订单量排行

从大盘、时间、品类、地域多维度完成业务复盘。

### 06 SQL 优化实战（EXPLAIN + 索引）
采用 **优化前 → 建索引 → 优化后** 对比实战：
- 无索引全表扫描 VS 单列索引优化
- 复合索引最左前缀原则验证
- 索引生效 & 索引失效场景对比
- 多表关联无索引 VS 关联字段加索引
通过 `EXPLAIN` 分析执行计划：
`type`、`key`、`rows`、`Extra` 关键指标解读，掌握真实工作 SQL 调优思路。
